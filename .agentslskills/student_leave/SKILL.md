# 学生请假条撰写规范

## 一、基本格式要求
1. 标题统一为"请假条"
2. 开头顶格写称呼："尊敬的XX老师："
3. 正文开头说明身份："我是XX年级XX班的学生XXX"
4. 明确说明请假原因和请假时间
5. 表达歉意并承诺补上落下的功课
6. 结尾使用"此致 敬礼"
7. 右下角注明请假人和日期

## 二、请假时长分类
### 1. 半天假
- 说明具体时间段（上午/下午第几节课到第几节课）
- 理由应简短直接，无需过多细节
- 适合临时身体不适、家长接送等情况

### 2. 一天假
- 说明完整的日期
- 理由需要有一定的合理性和说服力
- 适合感冒发烧、轻微疾病、家庭事务等

### 3. 多天假（2-7天）
- 明确说明请假起止日期
- 理由需要更详细，必要时说明证明材料
- 适合较严重疾病、家人住院、外地探亲等

## 三、真实请假理由写法
### 1. 生病类
- 感冒发烧："我今天早上起床后感到头晕乏力，体温38.5度，医生建议在家休息一天"
- 肠胃炎："我昨晚吃坏了东西，上吐下泻，身体非常虚弱，需要在家休息"
- 外伤："我昨天不小心摔倒，膝盖擦伤严重，医生建议在家休养两天"
- 过敏："我突发过敏性鼻炎/荨麻疹，需要去医院就诊并在家休息"

### 2. 家庭事务类
- 家人就医："我的家人今天需要去医院做检查，需要我陪同前往"
- 家庭急事："家里有紧急事务需要处理，特此请假一天"
- 外地探亲："我的外地亲戚来访，需要我去车站接送并陪同一天"

## 四、合理借口写法（语气自然，避免夸张）
### 1. 身体不适类（最常用且最合理）
- "我今天早上起来肚子有点不舒服，想请假半天在家休息"
- "我有点头痛，精神状态不好，担心影响上课，想请假一天"
- "我昨晚没睡好，今天上课注意力无法集中，想请假回家休息"
- "我牙齿有点痛，需要去看牙医，特此请假半天"

### 2. 家庭事务类
- "我家里的水管/电器坏了，维修人员今天上午上门，需要我在家等候"
- "我需要去银行/派出所办理一些个人事务，只能在工作日办理"
- "我的家长今天有事，需要我去接弟弟/妹妹放学"

## 五、绝对避免的借口
1. 过于夸张或不合逻辑的理由
2. 涉及违法违规的内容
3. 明显是编造的谎言
4. 对老师不尊重的表述

## 六、语气和措辞要求
1. 语气诚恳、礼貌、谦逊
2. 用词简洁明了，避免冗长
3. 不要使用网络用语或口语化表达
4. 表达对老师的尊重和感谢
5. 主动承诺会补上落下的功课和作业

## 七、示例模板

### 示例1：半天假（身体不适）

```
请假条

尊敬的XX老师：

我是XX年级XX班的学生XXX。因今天上午起床后感觉肚子不舒服，想请假半天回家休息。上午的课我会尽量自己看书学习，下午若无大碍会及时返校。

由此给老师带来的不便，深表歉意，请老师批准。

此致
敬礼

请假人：XXX
2026年4月27日
```

### 示例2：一天假（真实生病）

```
请假条

尊敬的XX老师：

我是XX年级XX班的学生XXX。我于昨晚吃坏了东西，今早起床后上吐下泻，身体非常虚弱，体温38.2度。家长已带我去医院就诊，医生诊断为急性肠胃炎，建议在家休息一天。

今天落下的功课我会主动找老师同学补上，请老师放心。

此致
敬礼

请假人：XXX
2026年4月27日
```

### 示例3：多天假（家庭事务）

```
请假条

尊敬的XX老师：

我是XX年级XX班的学生XXX。我的外公从外地过来探亲，今天抵达我市火车站，需要家人接站并陪同。同时，家里还有一些家庭事务需要处理，特请假三天（4月28日至4月30日）。

5月1日（周三）我会正常返校上课。落下的功课我会利用假期时间自学补上，请老师批准。

此致
敬礼

请假人：XXX
2026年4月27日
```
